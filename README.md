# EasyMatrix 像素时钟

EasyMatrix 是一款基于 **ESP32** 与 **WS2812 8×32（4个 8×8 级联）RGB 像素屏** 的多功能桌面像素时钟与音频律动仪。集成了 NTP 网络自动对时、SoftAP 网页配网、自定义颜色、多种音频 FFT 音乐频谱律动、像素艺术动画与自适应环境光调光等功能。

---

## 硬件配置与引脚接线

| 外设/功能 | 引脚 (GPIO) | 说明 |
| :--- | :--- | :--- |
| **WS2812 点阵屏数据输入** | **GPIO 6** | 8×32 阵列，共 256 颗 RGB 灯珠 |
| **按键 1 (BTN1)** | **GPIO 5** | 右/递增/切换模式（上拉输入） |
| **按键 2 (BTN2)** | **GPIO 4** | 左/递减/切换模式（上拉输入） |
| **按键 3 (BTN3)** | **GPIO 8** | 页面切换 / 模式长按设置（上拉输入） |
| **音频拾音器 (麦克风)** | **GPIO 1** | 模拟信号输入（ADC），用于音频采样与 FFT 计算 |
| **光敏电阻 (环境光检测)** | **GPIO 2** | 模拟信号输入（ADC），用于自动亮度控制 |
| **随机数种子引脚** | **GPIO 11** | 悬空引脚，读取模拟噪声生成伪随机数种子 |

## 功能页面与操作指南

系统拥有 4 个主要功能页面，短按 **按键 3** 可依序循环切换：

$$\text{时间页面 (TIME)} \longrightarrow \text{音乐律动 (RHYTHM)} \longrightarrow \text{像素动画 (ANIM)} \longrightarrow \text{亮度调节 (BRIGHT)} \longrightarrow \text{时间页面}$$

### 1. 时间页面 (TIME)
- **按键 1 / 按键 2 (短按)**：在三种时间格式之间切换：
  - 时:分:秒 (`HH:MM:SS`)
  - 时:分 (`HH:MM`)
  - 日期 (`MM-DD` + 星期)
- **按键 3 (长按 1.2s)**：在 **平滑滚动动画** 与 **直接数字跳变** 两种过渡模式之间切换。

### 2. 音乐律动页面 (RHYTHM)
- **按键 1 / 按键 2 (短按)**：在 4 种律动频谱样式间循环切换：
  - 模式 1：渐变全彩柱状图
  - 模式 2：经典峰值下落单色柱状图
  - 模式 3：双色彩虹柱状图
  - 模式 4：动态彩虹频谱柱状图
- **按键 3 (长按 1.2s)**：切换频段排布：
  - 模式 1：标准顺序（左低频 $\to$ 右高频）
  - 模式 2：对称布局（中间低频 $\to$ 两侧高频）

### 3. 像素动画页面 (ANIM)
- **按键 1 / 按键 2 (短按)**：在 3 种像素动态艺术效果间切换：
  - 模式 1：跳跃小海豚
  - 模式 2：黑客帝国数字雨 (Matrix Rain)
  - 模式 3：随机星光散落粒子
- **按键 3 (长按 1.2s)**：**重新配网**。系统会保存配网标志并立即重启，进入 SoftAP 配网热点模式。

### 4. 亮度调节页面 (BRIGHT)
- **手动模式下按键 1 / 按键 2 (短按)**：步进增减点阵屏全局亮度（范围：5 ～ 145，步长 20）。
- **按键 3 (长按 1.2s)**：在 **手动调光 (MANUAL)** 与 **环境光自适应调光 (AUTO)** 之间切换。

## 局域网常驻 Web 控制台与 OTA 空中升级

设备成功连入家庭 Wi-Fi 后，Web 服务器将在局域网中**常驻运行**，无需安装任何 App，在手机或电脑浏览器中直接输入设备的 IP 地址（如 `http://192.168.1.105`）即可打开全功能控制台：

### 1. Web 实时控制台主要功能
* **设备状态监控**：实时展示当前运行页面、局域网 IP、Wi-Fi 信号强度 (RSSI)、系统运行时间及空闲内存 (Free Heap)。
* **主页面远程切换**：在网页端一键切换「时钟时间」、「音乐律动」、「像素动画」、「亮度调节」。
* **模式与效果细调**：
  * **时钟**：切换时分秒/时分/日期星期格式；切换翻页动画与直接跳变。
  * **律动**：切换 4 种频谱柱样式与 2 种频段对称排布。
  * **动画**：切换跃水小海豚、黑客帝国代码雨、星光散落粒子。
  * **亮度**：切换手动调光/光敏自适应；提供 5~145 实时亮度拖动滑块。
* **色彩实时自定义**：网页内置拾色器与 RGB 输入，支持色块实时预览与一键保存持久化。
* **屏幕弹幕与跑马灯**：在网页输入英文/数字消息，点击一键推送到 8×32 屏幕上平滑滚动展示。
* **系统维护**：支持网页端远程重启设备与一键重置热点配网。

### 2. OTA 固件在线升级 (Over-The-Air Update)
* 在控制台的「固件在线升级」区域（或直接访问 `http://<设备IP>/update`），选择编译生成的 `.bin` 固件文件。
* 点击「开始空中升级」，控制台将显示实时上传与烧录百分比进度条，点阵屏将显示 `OTA..`。
* 固件烧录完成后，点阵屏显示 `OTA OK`，设备自动重启生效并于 10 秒后自动刷新页面，彻底告别 USB 连线烧录。

## 首次使用与配网说明

1. 初次上电或无 WiFi 配置信息时，设备会自动进入配网页面（屏幕显示 `CONFIG` 或滚动播放 IP 地址）。
2. 使用手机或电脑连接由设备发出的 WiFi 热点：
   - **热点名称 (SSID)**：`EasyMatrix`
   - **默认密码**：无密码或根据代码默认
3. 连接成功后，在浏览器中打开：
   $$\text{http://192.168.1.1}$$
4. 在配网页面中：
   - 选择目标 WiFi 名称并输入密码。
   - 可输入 **RGB 颜色数值 (0-255)** 自定义时间数字的显示色彩。
5. 点击提交，设备将自动尝试连接 WiFi 并进行 NTP 网络授时。授时成功后自动进入时间显示。

## 固件编译与烧录提示

- **主控平台**：ESP32（推荐 ESP32 Arduino Core 2.0.x / 3.x）
- **开发工具**：Arduino IDE / PlatformIO
- **必要依赖库**：
  - `Adafruit NeoPixel`
  - `Adafruit NeoMatrix`
  - `Adafruit GFX Library`
  - `arduinoFFT` (推荐 1.6.x 兼容版本)
  - `OneButton`
  - `Ticker`
- **字体替换**：如需显示专属微型英文字符，请按作者视频说明将附带的 `MyFont` 文件覆盖至 GFX 库的 `Fonts` 目录下。
- **重要烧录设置**：烧录固件时，务必在 IDE 的开发板菜单中将 **`Erase All Flash` 选为 `Enable`**，防止此前残存的 NVS 分区数据结构引起异常。

## 版本日志 (Changelog)

### 2024-06-16 — V1.6 (功能扩展版本)
1. **新增局域网常驻 Web 控制台**：连入家庭 Wi-Fi 后 WebServer 保持常驻，手机/电脑浏览器直接访问设备 IP 即可进入全功能深色控制台。
2. **支持全参数无线远程控制**：在网页端自由切换主页面（时钟/律动/动画/亮度）、调节子模式、滑动调节亮度、实时调色并保存。
3. **新增屏幕实时弹幕/跑马灯**：通过 Web 端发送自定义英文或数字消息，点阵屏即时平滑滚动显示，按任意按键可随时取消退出。
4. **新增 Web OTA 在线固件空中升级**：集成 ESP32 `<Update.h>` 原生升级协议与带进度条的前端上传组件，告别数据线，直接网页上传 `.bin` 固件一键升级并自动重启。
5. **网络持久化与自动重连**：启用 ESP32 `setAutoReconnect` 机制，移除以往对时后断开 Wi-Fi 的逻辑，实现全天候稳定在线。

### 2024-06-15 — V1.5 (优化与定制版本)
1. **移除闹钟功能与无用代码**：完全移除闹钟设置页面、闹钟定时器、响铃任务及蜂鸣器音乐播放模块（清理了 `buzzer.cpp/h`、`songs.h`、`img/bell.h` 等），大幅节省 Flash 存储与运行时 RAM。
2. **精简页面流转与交互**：主页面简化为 `TIME` $\to$ `RHYTHM` $\to$ `ANIM` $\to$ `BRIGHT` 循环，去除了冗余按键事件与无效分支。
3. **修复 ODR 违反与内存越界**：修正 `light.h` 中 `matrixArray` 二维数组声明尺寸与定义尺寸不一致的问题，确保数组清零与访问安全。
4. **提升 FreeRTOS 任务安全性**：封装 `safeDeleteTask`，杜绝 `vTaskDelete(NULL)` 错杀调用者及悬空任务句柄问题；将子任务栈容量提升至 2048 字节，避免栈溢出崩溃。
5. **消除除零与越界隐患**：FFT 频谱加入高度保护与防除零截断，杜绝空音频输入时的崩溃或数组越界。
6. **优化环境光自适应曲线**：改用二次 Gamma 响应与低通平滑滤波算法，消除光敏采样跳变引起的屏闪。
7. **修复看门狗复位死循环**：为动画 3 的随机粒子寻址增加最大重试计数保护，防止因空闲点位耗尽触发硬件 WDT 复位。
