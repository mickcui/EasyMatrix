## 📖 项目简介

**EasyMatrix** 是一款专为极客与桌面美学爱好者设计的智能 RGB 像素点阵时钟。硬件核心基于 ESP32 芯片，搭配由 4 块 8×8 级联组成的 8×32 WS2812B RGB 像素屏。

不同于传统单片机时钟，EasyMatrix 不仅具备毫秒级精度的 NTP 网络时间同步与丰富的艺术特效，更内嵌了基于 WebServer 的全功能局域网深色控制台与 RESTful API，支持通过电脑或手机浏览器进行全参数遥控、RGB 拾色调色、实时弹幕推送以及 Web OTA 固件在线升级。

## 🌟 核心功能亮点

1. **多样化时间显示 (TIME)**
   - 包含 3 种时间布局：**时:分:秒** (`HH:MM:SS`)、**时:分** (`HH:MM`)、**月-日+星期指示** (`MM-DD`)。
   - 支持 **平滑滚动翻页动画** 与 **直接数字跳变** 两种视觉过渡模式。
   - 星期状态指示条采用互补色/反色算法动态高亮，美观协调。

2. **32 频段高精音频律动频谱 (RHYTHM)**
   - 采用模拟麦克风采集音频信号，运用 `arduinoFFT` 进行实时快速傅里叶变换与频段聚合。
   - **4 种频谱色彩主题**：渐变全彩柱状图、下落峰值单色柱、双色彩虹柱、动态色彩流转柱。
   - **2 种频段对称排布**：标准顺序（左侧低频 $\to$ 右侧高频）与对称布局（中间低频 $\to$ 两侧高频）。
   - 算法内置动态自适应高度缩放，避免高音量整体冲顶爆表。

3. **趣味艺术像素动画 (ANIM)**
   - **跃水海豚**：逐帧重绘的海豚逐浪跳跃动画。
   - **黑客帝国 (Matrix Rain)**：下坠字符流模拟数字雨经典效果。
   - **星光呼吸散落**：随机像素粒子亮起与熄灭，内含防死循环防看门狗复位保护机制。

4. **双模亮度自适应调节 (BRIGHT)**
   - **手动模式 (MANUAL)**：提供 5 ～ 145 亮度范围（步长 20）线性调节。
   - **自动模式 (AUTO)**：采集光敏电阻 ADC 读数，通过二次 Gamma 曲线感知映射与一阶低通滤波算法，平滑跟随环境光变化，无屏闪抖动。

5. **局域网常驻深色 Web 控制台**
   - 连入 WiFi 后局域网 WebServer **全天候常驻运行**，无需安装 App，手机/电脑访问设备 IP 即可秒开。
   - **状态监控**：实时查看当前运行页面、WiFi 信号强度 (RSSI)、系统运行时间及 Free Heap 空闲内存。
   - **远程遥控**：在网页端随时一键切换主页面、时钟布局、律动模式、动画特效与亮度模式。
   - **RGB 调色拾色器**：内置取色盘与十六进制代码显示，支持色块实时预览与持久化保存。

6. **实时屏幕弹幕 / 滚动消息 (Marquee)**
   - 通过 Web 控制台或 HTTP API 随时向时钟发送自定义英文或数字消息。
   - 消息以约 22 FPS 平滑步进在 8×32 屏幕上滚动播放，支持指定循环次数。
   - 播放期间按下设备任意物理按键即可即时退出并恢复之前页面。

7. **Web OTA 空中无线固件升级 (Over-The-Air)**
   - 集成原生 `<Update.h>` 升级协议，在 Web 控制台内可直接上传编译好的 `.bin` 固件。
   - 升级期间带实时上传百分比进度条与屏幕提示（`OTA..` $\to$ `OTA OK`），升级完毕自动重启生效，告别 USB 数据线。

8. **NVS 全局持久化与自动恢复**
   - 所有的网络配置、时钟主题色彩、当前子页面选择、频谱布局、跳变模式和亮度配置均实时写入 ESP32 NVS（Non-volatile Storage），断电重启依然保持用户偏好。

## 🛠 硬件配置与接线说明

### 1. 硬件选型建议

| 部件 | 推荐型号/规格 | 数量 | 备注 |
| :--- | :--- | :--- | :--- |
| **主控板** | ESP32 开发板 / ESP32-C3 核心板 | 1 | 推荐带 USB 转串口与外置天线或 PCB 天线板 |
| **RGB 点阵屏** | WS2812B 8×32 柔性屏（4 个 8×8 级联） | 1 | 256 颗灯珠，GRB 顺序，单线归零码通信 |
| **音频拾音器** | MAX9814 / 驻极体麦克风放大模块 | 1 | 模拟电压输出 (OUT) 接主控 ADC |
| **光敏电阻模块** | 带有模拟量输出 (AO) 的光敏传感器模块 | 1 | 用于检测环境照度，实现自动调光 |
| **轻触按键** | 6×6 轻触微动按键 | 3 | BTN1、BTN2、BTN3 |
| **电源供应** | 5V 2A ~ 3A 优质开关电源或适配器 | 1 | 灯珠全亮白色时功耗较大，供电必须充足 |

### 2. 引脚接线对照表

> **提示**：源码引脚定义位于 `common.h`。若使用其他 ESP32 核心板型号，可在 `common.h` 中根据实际布线修改引脚编号。

| 外设 / 功能模块 | 对应引脚 (GPIO) | 模式 / 信号特性 | 功能描述 |
| :--- | :--- | :--- | :--- |
| **WS2812 点阵屏 DIN** | **GPIO 6** | 数字输出 | 8×32 像素点阵屏串行信号输入 |
| **按键 1 (BTN1)** | **GPIO 5** | 上拉输入 (INPUT_PULLUP) | 模式向右递增 / 亮度递增 / 退出跑马灯 |
| **按键 2 (BTN2)** | **GPIO 4** | 上拉输入 (INPUT_PULLUP) | 模式向左递减 / 亮度递减 / 退出跑马灯 |
| **按键 3 (BTN3)** | **GPIO 8** | 上拉输入 (INPUT_PULLUP) | 循环切换主页面 / 长按功能模式设定 |
| **音频采集输入** | **GPIO 1** | 模拟输入 (ADC1) | 拾音器模拟音频信号输入（用于 FFT 计算） |
| **光敏传感器输入** | **GPIO 2** | 模拟输入 (ADC1) | 环境光模拟量输入（用于自动亮度控制） |
| **伪随机数种子引脚** | **GPIO 11** | 模拟悬空输入 | 读取悬空模拟噪声初始化随机数发生器 |
| **蜂鸣器 (预留)** | **GPIO 0** | 数字输出 | 硬件预留，当前固件默认未启用 |

### 3. 电气接线与供电注意事项

1. **电源共地 (Common GND)**：点阵屏的电源地、ESP32 开发板的 GND 以及传感器的 GND **必须全部牢固连接在一起**。
2. **大电流供电**：256 颗 WS2812 灯珠在全开高亮状态下峰值电流可超 2.5A。强烈建议**从 5V 电源输出端分流供电**——一路接点阵屏的 5V/GND，另一路接 ESP32 的 5V(VIN)/GND，切忌直接通过 ESP32 板载 LDO 给整块点阵屏供电，否则会导致电压跌落、ESP32 异常重启甚至烧毁芯片！
3. **信号滤波**：若出现灯珠偶发闪烁或色彩错乱，可在点阵屏 5V 与 GND 两端并联一个 470μF~1000μF 电解电容，并在 GPIO 6 数据输出端串联一颗 220Ω~470Ω 的限流电阻。

## 🎮 按键交互与操作指南

系统拥有 **4 个主要功能页面**，短按 **按键 3 (BTN3)** 可依序单向循环切换：

```text
[时间页面 TIME] ──(短按BTN3)──> [音乐律动 RHYTHM] ──(短按BTN3)──> [像素动画 ANIM] ──(短按BTN3)──> [亮度调节 BRIGHT] ──(短按BTN3)──> [时间页面 TIME]
```

### 综合按键操作对照表

| 当前页面 | 按键 1 (BTN1) 短按 | 按键 2 (BTN2) 短按 | 按键 3 (BTN3) 短按 | 按键 3 (BTN3) 长按 (>1.2s) |
| :--- | :--- | :--- | :--- | :--- |
| **时间页面 (TIME)** | 顺切时间格式：<br>`HH:MM:SS` $\to$ `HH:MM` $\to$ `MM-DD` | 逆切时间格式：<br>`HH:MM:SS` $\to$ `MM-DD` $\to$ `HH:MM` | 切换至 **音乐律动** 页面 | 切换时间数字过渡：<br>**滚动动画** $\leftrightarrow$ **直接跳变** |
| **音乐律动 (RHYTHM)** | 顺切 4 种律动频谱主题 | 逆切 4 种律动频谱主题 | 切换至 **像素动画** 页面 | 切换频段排布：<br>**标准左低右高** $\leftrightarrow$ **中间对称** |
| **像素动画 (ANIM)** | 顺切 3 种动画特效：<br>海豚 $\to$ 黑客 $\to$ 星光 | 逆切 3 种动画特效：<br>海豚 $\to$ 星光 $\to$ 黑客 | 切换至 **亮度调节** 页面 | **重新配网**：<br>保存标志并立即重启进 SoftAP |
| **亮度调节 (BRIGHT)** | 手动模式下：**增加亮度**<br>(每次 +20，最高 145) | 手动模式下：**减少亮度**<br>(每次 -20，最低 5) | 切换至 **时间页面**<br>(若未对时则进律动) | 切换亮度模式：<br>**手动模式** $\leftrightarrow$ **环境光自适应** |
| **配网页面 (SETTING)** | 退出当前弹幕（若有） | 退出当前弹幕（若有） | 跳过配网：<br>有历史配置则尝试重连，无则进律动 | — |
| **任何播放弹幕中** | 立即打断并退出弹幕 | 立即打断并退出弹幕 | 立即打断并退出弹幕 | — |

## 💻 局域网 Web 控制台与 RESTful API

设备成功联网后，在同局域网内的手机或电脑浏览器中直接输入设备的 IP 地址（如 `http://192.168.1.105`）即可打开全功能现代深色控制台。

### 1. Web 界面功能区

- **实时状态仪表盘**：顶栏实时轮询显示当前页面、局域网 IP 地址、WiFi 信号强度 (RSSI) 及设备已开机运行时长。
- **主功能一键切换**：快速在时间、律动、动画、亮度之间无缝切换。
- **个性化细调组件**：根据当前所选页面动态展开对应子面板，调整时间格式、频谱样式、频段排布与动画效果。
- **全彩 RGB 调色板**：直观的调色板控件，支持调色后一键下发到点阵屏并持久化保存。
- **屏幕弹幕广播**：输入自定义文字内容，一键在屏幕上平滑滚动。
- **无线固件更新 (OTA)**：内置拖拽上传组件，支持在线刷写 `.bin` 固件。

### 2. 开放式 RESTful HTTP API

EasyMatrix 原生提供丰富的 HTTP 接口，极度方便与 **Home Assistant**、**Node-RED**、**快捷指令** 或各类自动化脚本进行集成联动。

#### 1) 获取设备运行状态
- **请求方式**：`GET /api/status`
- **响应格式**：`application/json`
- **响应示例**：
```json
{
  "page": "TIME",
  "pageId": 1,
  "timePage": 1,
  "timeModel": 2,
  "rhythmPage": 1,
  "bandsModel": 1,
  "animPage": 1,
  "brightModel": 1,
  "brightness": 45,
  "color": [0, 250, 250],
  "ip": "192.168.1.105",
  "rssi": -48,
  "heap": 178240,
  "uptime": 3600
}
```

#### 2) 设备控制接口
- **请求方式**：`POST /api/control`
- **支持参数（URL Query 或 Form 表单）**：

| 参数名 | 类型 / 取值范围 | 作用说明 |
| :--- | :--- | :--- |
| `page` | `TIME` / `RHYTHM` / `ANIM` / `BRIGHT` | 切换主工作页面 |
| `timePage` | `1` / `2` / `3` | 设置时间显示格式（1: 时分秒，2: 时分，3: 日期星期） |
| `timeModel` | `1` / `2` | 设置时间跳变模式（1: 数字直接跳变，2: 滚动动画） |
| `rhythmPage` | `1` ~ `4` | 设置音频律动柱状图样式主题 |
| `bandsModel` | `1` / `2` | 设置频段排布（1: 左低右高，2: 对称排布） |
| `animPage` | `1` ~ `3` | 设置像素动画效果（1: 小海豚，2: 黑客帝国，3: 随机星光） |
| `brightModel`| `1` / `2` | 设置调光模式（1: 手动，2: 光敏自适应） |
| `brightness` | `5` ~ `145` | 设置手动模式下的屏幕全局亮度 |
| `red`, `green`, `blue` | `0` ~ `255` | 批量设置时钟主色彩并更新星期条互补色 |
| `reboot` | `true` | 重启 ESP32 主控 |
| `resetWifi` | `true` | 清除配网标志并立即重启进入 SoftAP 热点配网 |

**调用示例 (cURL)**：
```bash
# 切换至时间页面并设置亮度为 65
curl -X POST "http://192.168.1.105/api/control?page=TIME&brightness=65"

# 修改时钟颜色为橙红色 (RGB: 255, 120, 0)
curl -X POST "http://192.168.1.105/api/control?red=255&green=120&blue=0"
```

#### 3) 发送跑马灯弹幕
- **请求方式**：`POST /api/message`
- **参数说明**：
  - `text` (必填)：滚动显示的英文字符符串（例如：`HELLO WORLD`）。
  - `repeat` (选填)：播放重复次数，取值范围 `1` ~ `5`，默认为 `2`。
- **调用示例 (cURL)**：
```bash
curl -X POST -d "text=WELCOME&repeat=2" "http://192.168.1.105/api/message"
```

#### 4) OTA 固件升级接口
- **请求方式**：`POST /update`
- **类型**：`multipart/form-data`
- **说明**：上传编译后的固件文件（参数名：`update`），设备将实时写入 Flash 并在完成后自动重启。

## 📶 首次使用与 SoftAP 配网说明

若设备首次上电、未保存过网络信息或长按按键重新触发配网，系统将自动进入 SoftAP 配网模式：

1. **观察屏幕指示**：
   - 屏幕将平滑轮播滚动显示提示 IP：`192.168.1.1`。
2. **连接设备热点**：
   - 使用手机或电脑搜索并连接设备发出的无密码 Wi-Fi 热点：
     - **热点名称 (SSID)**：`EasyMatrix`
     - **热点密码**：无密码
3. **打开配置页面**：
   - 连接成功后，打开手机或电脑浏览器，访问：`http://192.168.1.1`
4. **填写网络与参数**：
   - 页面已自动扫描并列出周围的 2.4GHz Wi-Fi 信号及强弱指示。
   - 在下拉菜单中选择家中的 Wi-Fi 名称并输入密码。
   - 下方可预设时钟开机默认显示色彩的 **RGB 数值 (0-255)**。
5. **保存并生效**：
   - 点击 **提交** 按钮，设备保存配置并自动重启。
   - 随后设备将自动连接目标 Wi-Fi，并请求阿里云与中科院 NTP 服务器对时。
   - 授时完成后屏幕将显示当前精确网络时间，并开启常驻局域网 Web 控制台。

> **提示**：若已联网状态下想手动重新配置网络，可直接访问 `http://<设备IP>/wifi`，或在动画页面长按 **按键 3**。

## 🔨 固件编译与烧录指南

### 1. 开发环境选择

推荐使用 **Arduino IDE 2.x** 或 **VS Code + PlatformIO**。

#### A. 必要依赖库列表

请通过 Arduino 库管理器（Library Manager）搜索并安装以下库：

| 依赖库名称 | 推荐版本 | 作用 |
| :--- | :--- | :--- |
| **Adafruit GFX Library** | 1.11.x 或最新 | 核心图形驱动库 |
| **Adafruit NeoMatrix** | 1.3.x 或最新 | 矩阵排列驱动库 |
| **Adafruit NeoPixel** | 1.12.x 或最新 | WS2812 物理底层时序驱动 |
| **arduinoFFT** | 1.6.x (如 1.6.2) | 32 频段音频 FFT 快速傅里叶变换 |
| **OneButton** | 2.5.x 或最新 | 按键消抖、单击与长按事件监听 |
| **ArduinoJson** | 6.x 或 7.x | JSON 数据序列化与 API 解析 |

> **重要：替换微型定制字体**  
> 为保证 8×32 紧凑屏幕能完整显示英文字符与数字，本项目采用了精简微型点阵字体：
> 1. 请在 Arduino 开发环境库目录中找到：`libraries/Adafruit_GFX_Library/Fonts/`
> 2. 将项目附带或定制的 `MyFont.h` 文件复制放入该 `Fonts` 目录下。

#### B. PlatformIO 配置参考 (`platformio.ini`)

若使用 PlatformIO，可参考以下配置工程：

```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200
board_build.flash_mode = qio
board_build.partitions = default.csv
lib_deps =
    adafruit/Adafruit GFX Library
    adafruit/Adafruit NeoMatrix
    adafruit/Adafruit NeoPixel
    kosme/arduinoFFT @ ^1.6.2
    mathertel/OneButton
    bblanchon/ArduinoJson
```

### 2. 核心烧录设置（重要避坑）

在 Arduino IDE 菜单项中配置：
1. **Board**：选择你的 ESP32 型号（例如 `ESP32 Dev Module` 或 `ESP32C3 Dev Module`）。
2. **Flash Size**：`4MB (32Mb)`。
3. **Partition Scheme**：`Default 4MB with spiffs` 或 `Minimal SPIFFS (Large APPS with OTA)`（推荐预留 OTA 分区）。
4. **Erase All Flash Before Sketch Upload**：**务必选择 `Enable`（完全擦除 Flash）**！
   - *原因*：首次烧录或大版本升级时，旧版残留的 NVS 结构可能导致变量读取异常；完全擦除后再行烧录，设备上电会自动以出厂默认状态进入配网模式。

## ❓ 常见问题排查 (FAQ)

### Q1: 点阵屏部分灯珠乱闪、发白或者 ESP32 在开机时不断重启？
- **A**：典型的供电不足或未共地引起。WS2812 8×32 阵列在亮度较高时瞬态电流极大。请务必使用独立的 5V 2A~3A 电源为灯板直接供电，并确认电源地（GND）与 ESP32 地线连接在一起。

### Q2: 编译时报错 `Fonts/MyFont.h: No such file or directory`？
- **A**：本项目使用了定制的微型英文点阵字库。请将包含该字体的头文件放置到 `Adafruit_GFX_Library` 的 `Fonts/` 子文件夹内，或将 `#include <Fonts/MyFont.h>` 改为本地相对路径包含。

### Q3: 为什么设备连上 Wi-Fi 之后依然显示时间对时失败？
- **A**：请确认您的路由器能正常访问外网，并且未阻断 UDP 123 端口（NTP 协议端口）。代码中默认轮询阿里云与中科院 NTP 服务器，如网络受限可于 `common.h` 中的 `NTP1`、`NTP2` 修改为路由器内网 NTP 服务器地址。

### Q4: 如何恢复出厂设置并重新配网？
- **A**：有三种便捷方式：
  1. 在 **像素动画 (ANIM)** 页面下，长按 **按键 3** 超过 1.2 秒，设备会自动记录配网标志并重启；
  2. 在 Web 控制台的「系统维护」卡片中点击「重新配网」；
  3. 通过 HTTP 请求发送：`POST http://<设备IP>/api/control?resetWifi=true`。
