## 📖 项目简介

**EasyMatrix** 是一款专为桌面极客与 DIY 爱好者设计的像素时钟与音频桌面摆件。采用 **ESP32** 主控配合 **4 个 8×8 级联（共 8×32 阵列，256 颗 RGB 灯珠）** 点阵屏。

### 🌟 核心特性
- ⏰ **高精度时间展示**：NTP 网络自动校准 RTC 时间，支持 3 种版式（时分秒 / 时分 / 日期星期）与 2 种跳变动效（平滑滑动翻页 / 直接跳变）。
- 🎵 **音频 FFT 音乐律动灯**：麦克风模拟采集 + 256 点快速傅里叶变换，4 种全彩频谱动态柱 + 2 种频段对称排布。
- 👾 **精美像素动态艺术**：跳跃小海豚、黑客帝国代码雨、星光散落粒子动画。
- 💡 **环境光自适应调光**：支持手动阶梯调节与光敏电阻环境光检测，采用非线性二次 Gamma 曲线和低通滤波平滑无频闪调光。
- 📱 **局域网常驻 Web 控制台**：连入家庭 Wi-Fi 后常驻运行，手机/电脑免 App 访问 IP 即可远程无线调控、改颜色、发弹幕。
- 🚀 **Web OTA 空中固件升级**：集成 ESP32 `<Update.h>` 原生流式上传，浏览器端直接上传 `.bin` 固件无线刷机，无需再插 USB 线。
- 💬 **实时屏幕弹幕 / 跑马灯**：通过网页发送自定义消息，屏幕即时平滑滚动通知。
- 💾 **NVS 全参数断电记忆**：Wi-Fi 配置、主时钟 RGB 色彩、各个子页面模式与亮度断电均可自动保存，开机自恢复。

## 🛠️ 硬件配置与引脚接线

| 外设 / 模块 | ESP32 引脚 (GPIO) | 模式 / 功能说明 | 接线建议 |
| :--- | :--- | :--- | :--- |
| **WS2812 点阵屏 DIN** | **GPIO 6** | 数字输出，单总线驱动 256 颗灯珠 | 建议串联 330Ω ~ 470Ω 电阻防冲击 |
| **按键 1 (BTN1)** | **GPIO 5** | 内部上拉输入，右递增 / 切换子项 | 按键另一端接地 (GND) |
| **按键 2 (BTN2)** | **GPIO 4** | 内部上拉输入，左递减 / 切换子项 | 按键另一端接地 (GND) |
| **按键 3 (BTN3)** | **GPIO 8** | 内部上拉输入，主页面切换 / 模式长按 | 按键另一端接地 (GND) |
| **音频拾音器 (麦克风)** | **GPIO 1** | ADC 模拟输入，用于音频采集与 FFT 分析 | 拾音器 OUT 接 GPIO 1，VCC 接 3.3V/5V |
| **光敏电阻传感器** | **GPIO 2** | ADC 模拟输入，检测周围环境光照 | 与 10K 电阻分压后接入 GPIO 2 |
| **随机数浮空引脚** | **GPIO 11** | 模拟浮空，读取热噪声生成真随机种子 | 悬空不接任何外围 |

> **⚠️ 供电特别提醒**：256 颗 WS2812 全白全亮时电流可达数安培。虽然本固件已限制亮度在 5~145 范围并优化功耗，仍强烈建议使用 **5V 2A 或 5V 3A** 的优质独立开关电源为屏幕供电，并与 ESP32 共地 (GND)。

## 🎮 操作指南与按键速查

主页面通过短按 **按键 3** 依序循环流转：

$$\text{时间页面 (TIME)} \longrightarrow \text{音乐律动 (RHYTHM)} \longrightarrow \text{像素动画 (ANIM)} \longrightarrow \text{亮度调节 (BRIGHT)} \longrightarrow \text{时间页面}$$

### 按键操作速查表

| 当前页面 | 按键 1 (短按) | 按键 2 (短按) | 按键 3 (短按) | 按键 3 (长按 1.2秒) |
| :--- | :--- | :--- | :--- | :--- |
| **⏰ 时间页面 (TIME)** | 切换时间格式 (时分秒/时分/日期) | 反向切换时间格式 | 进入音乐律动页面 | 切换数字过度效果 (平滑滑动 / 直接跳变) |
| **🎵 音乐律动 (RHYTHM)** | 切换频谱样式 (1~4) | 反向切换频谱样式 | 进入像素动画页面 | 切换频段排布 (单向左低右高 / 对称中间低两端高) |
| **👾 像素动画 (ANIM)** | 切换动态壁纸 (海豚/代码雨/粒子) | 反向切换壁纸 | 进入亮度调节页面 | **重新配网** (重启并进入 SoftAP 配网热点) |
| **💡 亮度调节 (BRIGHT)** | 步进增加亮度 (+20) | 步进减少亮度 (-20) | 返回时间页面 | 切换调光模式 (手动调光 / 光敏自适应) |
| **💬 跑马灯弹幕中** | 取消播放并恢复页面 | 取消播放并恢复页面 | 取消播放并恢复页面 | 取消播放并恢复页面 |

## 🌐 局域网常驻 Web 控制台

设备连接家庭 Wi-Fi 后，控制台将在局域网中持续提供服务。无需下载第三方 App，在同一局域网下的手机、平板或电脑浏览器中直接输入设备的局域网 IP（例如 `http://192.168.1.105`）即可访问：

### 控制台核心功能模块
1. **状态仪表盘 (KPI Dashboard)**：实时监控当前页面、局域网 IP、Wi-Fi 信号强度 (RSSI)、系统运行时间及 Free Heap 内存可用量。
2. **主页面与模式远程遥控**：
   - 网页端一键切换时间、律动、动画、亮度主页面。
   - 细化调节各个页面的子显示格式、频段模式、过渡动画。
3. **滑块与自动调光**：拖动滑动条实现 5~145 屏幕亮度毫秒级无感调节，或一键切换至光敏自适应。
4. **RGB 时钟颜色实时定制**：内置 HTML5 颜色拾取器与 RGB 数值联动输入，实时预览配色，点击即保存生效并计算互补星期反色。
5. **实时屏幕弹幕 / 跑马灯**：网页端输入任意文本（英文/数字），点击发送，点阵屏立即启动平滑跑马灯滚动播报。
6. **远程快捷维护**：网页端一键远程重启系统，或一键重新进入热点配网模式。

## 🚀 Web OTA 固件空中升级

固件已集成 Web OTA 远程升级机制，后续更新固件再也不需要插拔 USB 线：

1. **导出编译固件**：
   - 在 Arduino IDE 中打开项目，点击顶部菜单：**项目 (Sketch)** $\to$ **导出已编译的二进制文件 (Export Compiled Binary)**。
   - 在源码目录的 `build/` 文件夹下找到生成的 `.bin` 固件文件。
2. **网页端上传烧录**：
   - 打开 Web 控制台底部的 **「🚀 固件在线升级 (OTA)」** 区域（或直接在浏览器访问 `http://<设备IP>/update`）。
   - 选择 `.bin` 固件文件，点击 **「开始空中升级」**。
3. **自动重启与校验**：
   - 上传过程中网页会实时展示写入百分比进度条，点阵屏同步显示 `OTA..`。
   - 烧录完毕后点阵屏显示 `OTA OK`，ESP32 自动重启生效，网页将于 10 秒后自动刷新，即刻完成升级。

## 📡 首次使用与 SoftAP 配网

1. 初次上电或无 Wi-Fi 配置时，点阵屏将循环滚动显示 `192.168.1.1`，设备发出名为 `EasyMatrix` 的开放式热点。
2. 使用手机或电脑连接该 Wi-Fi 热点，打开浏览器访问：
   $$\text{http://192.168.1.1}$$
3. 在弹出的配网门户中：
   - 下拉选择或输入家庭 Wi-Fi 名称与密码。
   - 支持自定义初次时钟的 RGB 颜色（默认 `0 250 250` 青色）。
4. 点击提交后，设备将自动重启并连入路由器，开始通过权威 NTP 服务器对时。

## 🔌 开放 HTTP RESTful API 速查

对于智能家居爱好者（如接入 Home Assistant、Node-RED 或通过 Python/Shell 脚本自动化控制），EasyMatrix 提供了直接的局域网 REST API：

| 端点 (Endpoint) | 方法 | 参数说明 | 返回示例 |
| :--- | :---: | :--- | :--- |
| `/api/status` | `GET` | 无 | 获取当前设备完整状态 JSON |
| `/api/control` | `POST` | `page=TIME/RHYTHM/ANIM/BRIGHT` | 切换主页面 |
| `/api/control` | `POST` | `brightness=5~145` | 调节屏幕亮度 |
| `/api/control` | `POST` | `red=0~255&green=0~255&blue=0~255` | 设置并持久化时钟主色彩 |
| `/api/control` | `POST` | `brightModel=1(手动)/2(自动)` | 切换调光模式 |
| `/api/control` | `POST` | `reboot=true` | 软重启设备 |
| `/api/control` | `POST` | `resetWifi=true` | 重置网络并重启进 SoftAP |
| `/api/message` | `POST` | `text=Hello&repeat=1~5` | 在屏幕上发送跑马灯弹幕 |
| `/update` | `POST` | `multipart/form-data` 上传 `.bin` 固件 | OTA 固件写入 |

## 💻 固件编译与环境配置

- **主控平台**：ESP32 Dev Module（ESP32-WROOM-32 / ESP32-S3 等）
- **编译环境**：Arduino IDE 2.x 或 PlatformIO
- **核心依赖库**（可在 Arduino 库管理器直接搜索安装）：
  - `Adafruit NeoPixel`
  - `Adafruit NeoMatrix`
  - `Adafruit GFX Library`
  - `arduinoFFT` (推荐 1.6.x 兼容版本)
  - `OneButton`
  - `Ticker`
  - `ArduinoJson`
- **微型字体替换**：如需显示专属微型英文字符，请按作者视频说明将附带的 `MyFont` 文件放置或覆盖至 Adafruit GFX 库的 `Fonts/` 目录下。
- **首次烧录设置**：建议在 IDE 菜单中将 **`Erase All Flash` 选为 `Enable`**，以清除旧版脏数据并生成全新的 NVS 分区。

### 2024-06-15 — V1.5 (优化与定制版本)
1. **移除闹钟功能与无用代码**：完全移除闹钟设置页面、闹钟定时器、响铃任务及蜂鸣器音乐播放模块（清理了 `buzzer.cpp/h`、`songs.h`、`img/bell.h` 等），大幅节省 Flash 存储与运行时 RAM。
2. **精简页面流转与交互**：主页面简化为 `TIME` $\to$ `RHYTHM` $\to$ `ANIM` $\to$ `BRIGHT` 循环，去除了冗余按键事件与无效分支。
3. **修复 ODR 违反与内存越界**：修正 `light.h` 中 `matrixArray` 二维数组声明尺寸与定义尺寸不一致的问题，确保数组清零与访问安全。
4. **提升 FreeRTOS 任务安全性**：封装 `safeDeleteTask`，杜绝 `vTaskDelete(NULL)` 错杀调用者及悬空任务句柄问题；将子任务栈容量提升至 2048 字节，避免栈溢出崩溃。
5. **消除除零与越界隐患**：FFT 频谱加入高度保护与防除零截断，杜绝空音频输入时的崩溃或数组越界。
6. **优化环境光自适应曲线**：改用二次 Gamma 响应与低通平滑滤波算法，消除光敏采样跳变引起的屏闪。
7. **修复看门狗复位死循环**：为动画 3 的随机粒子寻址增加最大重试计数保护，防止因空闲点位耗尽触发硬件 WDT 复位。
